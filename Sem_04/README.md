# 🌀 Semana 4: Nonlinear SVM and Introduction to Regression

<span class="badge badge-blue">🌀 Kernel Trick</span>
<span class="badge badge-green">📈 Regression</span>


## 🎯 Objectives

- Explain the basic idea behind the **kernel trick** in Support Vector Machines.
- Identify and compare the main kernel types used with SVM.
- Understand why a linear decision boundary may be insufficient for classifying complex datasets.
- Differentiate classification problems from regression problems in supervised learning.
- Understand the fundamental concepts of simple linear regression.


## 📌 Topics

- 🌀 Kernel Trick for Support Vector Machines
  - Limitations of Linear SVM
  - Nonlinear decision boundaries
  - Mapping data into a higher-dimensional feature space
  - The kernel trick
  - Kernel parameters and model complexity

- 🧩 Types of SVM Kernels
  - Linear kernel
  - Polynomial kernel
  - Radial Basis Function (RBF) kernel
  - Sigmoid kernel
  - Choosing an appropriate kernel

- 📈 Introduction to Regression
  - Regression as supervised learning
  - Classification vs regression
  - Continuous target variables
  - Input features and target values
  - Real-world regression problems

- 📏 Simple Linear Regression
  - Independent and dependent variables
  - Slope and intercept, Mean Squared Error (MSE)
  - Regression line


## 🧠 Activities

- 💬 Discuss examples of datasets that cannot be separated using a straight line.
- 🌀 Visualize how different kernels produce nonlinear decision boundaries.
- 🐍 Implement SVM classifiers using linear, polynomial, RBF and sigmoid kernels.
- 🔎 Compare how the kernel and its parameters affect model complexity and predictions.
- 📊 Identify whether different real-world problems require classification or regression.
- 📈 Train a simple linear regression model using Scikit-learn.
- 📏 Visualize the regression line, predictions and residual errors.
- 📝 Complete a short quiz about SVM kernels and introductory regression concepts.
