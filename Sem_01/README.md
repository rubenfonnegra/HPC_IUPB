# ⚡ Week 1: High Performace - How Do We Know If a Program Is “Fast”?

<span class="badge badge-blue">⚡ Performance</span> 
<span class="badge badge-green">🖥️ HPC Fundamentals</span>

## 🎯 Objectives

* Understand what computational performance means in the context of High Performance Computing.
* Measure and compare program execution time using appropriate performance metrics.
* Differentiate between latency, throughput, and computational throughput measured in FLOPS.
* Analyze parallel performance using speedup and efficiency.
* Understand strong and weak scaling and their role in evaluating parallel systems.


## 📌 Topics

* ⏱️ Measuring Computational Performance
  * Execution Time
  * Latency
  * Throughput

* 🧮 Floating-Point Operations per Second (FLOPS)

* 🚀 Parallel Performance
  * Speedup
  * Efficiency
  * Parallel Overhead

* 📈 Scalability
  * Strong Scaling
  * Weak Scaling



## 🧠 Activities

* 💬 Discuss what it actually means for one program to be “faster” than another.
* ⏱️ Measure the execution time of a simple computational program and compare different implementations.
* 📊 Calculate speedup and parallel efficiency using execution-time measurements.
* 📈 Analyze strong and weak scaling using a small set of experimental performance results.



> **💡 Weekly Challenge**
>
> Choose a computational task from your research area that you consider computationally expensive.
>
> * What would “better performance” mean for this task?
> * Which metric would you use to measure it: execution time, throughput, FLOPS, speedup, or efficiency?
> * What part of the task could potentially be parallelized?
> * Do you think the main limitation is computation, memory access, or something else?
