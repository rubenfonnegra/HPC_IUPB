# 🤖 Semana 5: Support Vector Regression and Model Evaluation

<span class="badge badge-blue">📈 Support Vector Regression</span>
<span class="badge badge-green">📊 Model Evaluation</span>


## 🎯 Objectives

- Understand the fundamentals of Support Vector Regression (SVR).
- Explain the differences between Support Vector Machines (SVM) and Support Vector Regression (SVR).
- Learn how to evaluate supervised learning models using appropriate performance metrics.
- Interpret classification metrics such as Accuracy, Precision, Recall, Specificity, F1-score, ROC Curve, and AUC.
- Evaluate regression models using Mean Squared Error (MSE), Mean Absolute Error (MAE), and the Coefficient of Determination (R²).
- Compare different models based on objective performance metrics.


## 📌 Topics

- 📈 Support Vector Regression (SVR)
  - From classification to regression
  - Support vectors in regression
  - Linear and nonlinear SVR
  - Choosing kernel functions
  - Advantages and limitations

- 📊 Model Evaluation for Supervised Learning

  ### 🎯 Classification Metrics
  - Accuracy
  - Confusion Matrix
  - Precision
  - Recall (Sensitivity)
  - Specificity
  - F1-score
  - Receiver Operating Characteristic (ROC) Curve
  - Area Under the Curve (AUC)

  ### 📈 Regression Metrics
  - Mean Squared Error (MSE)
  - Mean Absolute Error (MAE)
  - Coefficient of Determination (R²)

- 🔎 Selecting the appropriate metric
  - Imbalanced datasets
  - Classification vs. Regression evaluation
  - Trade-offs between different metrics


## 🧠 Activities

- 💬 Discuss why model evaluation is as important as model training.
- 🐍 Train a Support Vector Regression (SVR) model using Scikit-learn.
- 📈 Compare predictions from Linear Regression and SVR.
- 📊 Compute classification metrics using Scikit-learn.
- 📉 Interpret confusion matrices and ROC curves.
- 📏 Evaluate regression models using MSE, MAE, and R².
- 🔍 Compare multiple models and determine which performs best for different scenarios.
- 📝 Complete a short quiz on supervised learning evaluation metrics.
